# risk-aware-container-inspection

This repository provides the core implementation of:

**Risk-Aware Container Inspection via Uncertainty-Weighted Preference Learning and Counterfactual Regularization**

The repository mainly contains three parts:

1. Dataset
2. State Indicator Extraction
3. Decision Framework

---

## 1. Dataset

### 1.1 Public Dataset

The public container defect images used in this study were selected and reorganized from multiple publicly available container defect datasets on **Roboflow Universe**.

The dataset covers six defect categories:

- Fracture
- Dent
- Rust
- Deformation
- Scratch
- Hole

Due to the large size of the complete image dataset, only a small number of representative examples are currently provided in this repository. Additional dataset information and source links will be progressively updated.

Example data are provided in `Examples of small datasets.zip`.

> **Dataset Notice:** The original images obtained from Roboflow Universe remain subject to the licenses and terms specified by their respective dataset owners. This repository does not claim ownership of these third-party images. Users should refer to the original dataset pages and comply with the corresponding licenses before downloading, redistributing, or using the data.

### 1.2 Real-World Dataset

A real-world container dataset was additionally collected under practical inspection conditions and used only for independent testing.

The images were acquired using an area-scan camera, and the algorithms were deployed on an NVIDIA Jetson Orin Nano 8GB platform.

The collected images preserve variations in illumination, viewpoint, and container surface conditions encountered in practical inspection environments.

Due to the size of the dataset and data-sharing considerations, the complete real-world dataset is not currently included in this repository. Representative examples and additional information may be provided in future updates.

## 2. State Indicator Extraction

The code related to state indicator extraction is provided in `State Indicator Extraction.zip`.

Two visual models are used to construct the state representation:

- **Edge-enhanced FAPrompt-CLIP** for anomaly heatmap generation
- **Depth Anything** for depth map generation

The corresponding pretrained model weights can be downloaded from their official repositories.

The main structure is:

```text
State Indicator Extraction/
├── edge-enhanced FAPrompt-CLIP/
│   └── rl_data_process.py
│
├── Depth-Anything/
│   └── container_data_process.py
│
├── preference_label_example/
│   └── *.csv
│
└── confusion_index.py
```

### 2.1 Anomaly-Related Indicators

`rl_data_process.py` extracts four anomaly-related indicators from the anomaly heatmaps generated by edge-enhanced FAPrompt-CLIP:

1. Maximum heatmap value
2. Anomaly probability
3. Mean anomaly score
4. Anomaly ratio

### 2.2 Depth-Related Indicators

`container_data_process.py` extracts two depth-related indicators from the depth maps generated by Depth Anything:

1. Boundary transition entropy
2. Gradient strength in the color-band direction

### 2.3 Indicator Fusion

`confusion_index.py` integrates the anomaly-related and depth-related indicators to construct the six-dimensional state representation used by the subsequent inspection decision framework.

For convenient reproduction, example CSV files containing the extracted state indicators are also provided in the `preference_label_example/` folder.

These CSV files can be directly used by the decision framework without rerunning the complete visual feature extraction process.

## 3. Decision Framework

The core inspection decision framework is provided in the `Decision Framework/` folder.

```text
Decision Framework/
├── Bayesian posterior probability.py
├── RM_train.py
├── PPO_train.py
├── CF_risk_regularization.py
├── model.py
└── test.py
```

### `Bayesian posterior probability.py`

Computes the aggregated posterior inspection preference probability from multiple inspection judgments and generates the preference information used for reward learning.

### `RM_train.py`

Trains the reward model using inspection preference pairs and uncertainty weighting.

### `PPO_train.py`

Trains the inspection decision policy using Proximal Policy Optimization (PPO) with reward-model feedback.

### `CF_risk_regularization.py`

Implements counterfactual search and counterfactual risk regularization for policy optimization.

### `model.py`

Defines the neural network architectures used in reward learning and policy optimization.

### `test.py`

Evaluates the trained inspection policy on the test dataset and reports the inspection decision results.

The final policy outputs two possible actions:

```text
0 - No inspection
1 - Inspection
```
